# Generated output policy

Files under `src/` are the editable application source.

`dist/gemini-podcast-studio.html` is generated by `npm run build`. The file must not be edited directly. It must be rebuilt after source changes so the distributable reflects the current HTML, CSS and JavaScript source.

Generated differences under `dist/` are build results, not hand-authored changes. Review them as the reproducible consequence of source, Vite configuration or build-script changes.

The temporary `.single-file-build/` directory is disposable bundler output. A successful build removes it after the standalone HTML has passed verification.
