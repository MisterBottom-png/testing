# Deferred phases

After standalone production parity is accepted, separate tasks may address:

1. Replacing remaining service-registry decorators with narrower interfaces.
2. Any model/default migration requested at that time.
3. Retry, cancellation or generation-job changes.
4. TTS, caching or storage optimisation.
5. Free-tier optimisation.
6. Further UI or accessibility optimisation.

None of these are part of the production single-file build task.
