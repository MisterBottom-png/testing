# Directory guide

- `src/index.html`: application markup and ordered source references.
- `src/styles/`: reset, tokens, base, layout, components and responsive styling.
- `src/js/`: state, utilities, UI, Gemini transport, audio and startup code.
- `scripts/`: single-file build and verification scripts.
- `tests/`: extraction and source-order checks.
- `dist/gemini-podcast-studio.html`: generated self-contained application.
