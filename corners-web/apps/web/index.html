Уголки

Переведи все десять фишек в противоположный треугольник. Простая цель, за которой человечество успешно прячет десятки минут тактической злобы.

Онлайн P2P

Соединение идёт напрямую между телефонами. Коды длинные, потому что браузеры обожают превращать простую вещь в дипломатический договор.

2Вставь ответ соперника

Соперник пришлёт ответный код. Вставь его и подключись.

Правила

Два игрока занимают противоположные треугольники.

Цель

Первым перевести все 10 своих фишек в треугольник соперника.

Ход

  • Можно перейти на соседнее свободное поле.
  • Можно перепрыгнуть через любую соседнюю фишку на свободное поле сразу за ней.
  • За один ход разрешена цепочка из нескольких прыжков. Игра сама показывает все достижимые конечные поля.
  • Фишка, попавшая в целевой треугольник, больше не может выйти из него.

Управление

Нажми свою фишку, затем зелёное поле. Повторное нажатие на выбранную фишку отменяет выбор.
